# 03 · 场景与价值

## 谁在用

已有活跃用户的所有产品型独立开发者

## 三个典型场景

### 场景 A：多渠道反馈采集
- **触发**：定时（每日）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：邮件/应用商店/Discord/社群/问卷抓取 → 统一入库
- **收益**：省 0.5h/日 ≈ ¥1200/月

### 场景 B：去重聚类
- **触发**：事件（采集后）
- **之后**：相似反馈合并 → 主题聚类 → 频次统计
- **收益**：含于 W1

### 场景 C：情绪与优先级打标
- **触发**：事件（聚类后）
- **之后**：情绪识别 → 需求强度打分 → 流失风险标记
- **收益**：省 0.3h/日 ≈ ¥720/月

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 月省约 25h ≈ ¥2000 vs 订阅，回报比 >20 倍 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
